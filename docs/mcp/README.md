# Nuvy MCP Registry

This directory is the code-side registry for MCP integrations approved for evaluation by NuvyCore.

## Current program
The registry tracks 24 selected MCP integrations across six phases:
- F1 Engineering: GitHub, Notion, Sentry, Context7, Postman
- F2 Cora/QA: Meta WhatsApp Business Tools, Noveum, TestDriver, SolidPing
- F3 Security: VerifyMCP, AgentGlass, PromptBrake
- F4 Intelligence/Observability: OpenRouter, Tavily, PostHog, Cloudflare
- F5 Product/Marketing/BR: Figma, Canva, Meta Ads, Google Ads, Ahrefs, Google Search Console, BR Intelligence, Assinafy

Nothing in this registry activates credentials or production access by itself. Connection setup is performed separately and must follow POLICY.md.
